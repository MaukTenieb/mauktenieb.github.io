# Sons de la borne

Les sons de `borne-son.js` viennent d'enregistrements réels versés au domaine public (CC0 1.0, https://creativecommons.org/publicdomain/zero/1.0/). Chaque son existe en deux fichiers : `.ogg` (Opus) et `.mp3` (repli pour Safari).

## Sources

- Kenney (Kenney Vleugels), paquets UI Audio, RPG Audio et Impact Sounds. Licence : CC0 1.0, d'après le `License.txt` de chaque paquet. Fichiers pris dans l'archive `kenney-audio.zip` (SHA-256 `dc7ab0b9d26b4649ade22197e2eed5f33453097fd7b99a11a5e6403a289465df`) publiée sur GitHub : https://github.com/incorruptibleyt/AAA-GAME-DESIGN/releases/download/audio-pack/kenney-audio.zip. Pages d'origine : https://kenney.nl/assets/ui-audio, https://kenney.nl/assets/rpg-audio, https://kenney.nl/assets/impact-sounds.
- Benjamin Burnes (Abstraction), paquets « bb - Keyboard Sounds », « bb - Smol Mechanisms », « bb - Toolbox Rummaging », « bb - Fans and Drones », et NazdyNate, « Micro Pack - NazdyNate - Electromagnetic Sounds ». Licence : CC0 1.0, d'après le `_README.txt` de chaque paquet (« These sounds are public domain (Creative Commons 0) »). Fichiers pris dans le dépôt GitHub https://github.com/lavenderdotpet/CC0-Public-Domain-Sounds, commit `f2b6264f9ab89fabc266914c3654685d68c5a39b`. Page d'origine des paquets : https://gumroad.com/ben_burnes.

## Traitement commun

Conversion en mono 48 kHz ; filtre passe-haut (40 Hz pour les coups, 25 Hz pour le ventilateur, 50 Hz pour le bourdon) ; silences coupés ; fondus courts en entrée et en sortie ; niveau ramené à -16 dBFS RMS sur la partie active, crête plafonnée à -1 dBFS (boucle du ronronnement : -20 dBFS RMS) ; encodage Opus 56 kb/s (boucle : 48 kb/s) et MP3 64 kb/s. Poids total : 193 Ko en Ogg, 222 Ko en MP3.
